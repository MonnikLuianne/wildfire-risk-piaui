# Raw data

Active fire detections (focos de calor) for Piauí, 2015–2025, one CSV per year (`focos_PI_<year>.csv`).

- Source: INPE – Programa Queimadas (BDQueimadas), https://terrabrasilis.dpi.inpe.br/queimadas/bdqueimadas/
- Satellite: reference satellite only (AQUA_M-T), which keeps the series consistent across years
- Filters: country Brazil, state Piauí, 01 Jan – 31 Dec of each year
- Downloaded on: 2026-11-11
- Files are kept exactly as downloaded. Missing values are coded as -999 by INPE.
- Times (`DataHora`) are in UTC.
